## Checked and passing

- **Head:** every page has a unique title (28–60 chars) and description (135–155). There is one H1 per page. Canonicals are absolute and self-referencing. 404 and /book/confirmed are `noindex, follow`, have no canonical and are left out of the sitemap. OG images are 1200×630 and exist. `og:locale` is en_US.
- **JSON-LD:** it parses on all pages, with one `@graph` each. Org, WebSite, Service, BlogPosting (+`isPartOf` pillar, `citation`), Article, BreadcrumbList (depth-2 only), CollectionPage/ItemList and AboutPage are all present. There is no `Review`/`AggregateRating` (so no self-serving review risk). FAQ Q&A text matches the visible text exactly on all 6 FAQ pages.
- **Crawl:** robots.txt allows all crawlers and names the search, user and training bots. The sitemap is referenced and lists 18 canonical URLs. `not_found_handling: "404-page"` and `html_handling: "auto-trailing-slash"` are set. All `_redirects` rules are explicit 301s, exact paths before splats, with no chains. The hash-route script is on `/`. No internal link points to a broken URL.
- **AEO:** articles show a byline, Published/Updated `<time>`, Key takeaways, a TL;DR and question H2s. Money pages lead with direct answers, and the price/FAQ H2s are phrased as questions. Content is server-rendered.
- **Performance:** first-party JS per page is about 1.7 KB gz (base+analytics); `/launch-check` adds 5.4 KB, `/book` 0.9 KB. PostHog (`module.DdX6E69B.js`, 307 KB raw / 101 KB gz) loads only after `load`+idle and only on discoverdev.ai, so it's excluded per the 07 §13 budget. HTML is 14–18 KB gz, CSS ≤12 KB gz per page. Fonts are 3 woff2 files (100.6 KB) with 1 preloaded, `font-display: swap` and metric-matched fallbacks. The only images are SVG logos with width and height set. `/_astro/*` is immutable for 1 year.
- **Security:** nosniff, Referrer-Policy, Permissions-Policy, COOP, XFO DENY plus header CSP (`frame-ancestors`/`base-uri`/`object-src`/`form-action`). The meta CSP is hash-based with no `unsafe-inline`. `security.txt` is present and expires 2027-10-17.
- **hreflang:** the `i18n` config and `LOCALES` registry are ready. Add `en`/`ar`/`x-default` alternates only when `/ar` ships (05 §6).
- **AEOTester false positives:**
  - "Indexability 0/8": the tool treats the host-scoped `X-Robots-Tag: noindex` rules as applying to all pages. They only apply on workers.dev hosts.
  - "Image alt 0/5": the logos have `alt=""` inside links with `aria-label="DiscoverDev home"`, which is correct.
